> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `plugins/podcast-clip-scout/`, a skill that has Claude pick ranked short-form clip candidates from a timestamped transcript using a five-dimension rubric, backed by a small stdlib-only Python helper that parses transcripts, checks the picks and exports a cut list.

**Architecture:** `SKILL.md` carries the rubric and process; Claude reads numbered cues, writes `picks.json` citing cue numbers only (never typed timestamps), and the helper derives times from the cues, validates the picks and exports CSV/JSON. Three small modules (`pcs_transcript.py` parse, `pcs_picks.py` check, `pcs_export.py` export) and one CLI (`clips.py`). The scoring itself is unvalidated judgment; the helper proves only that the list is consistent.

**Tech Stack:** Python 3, standard library only (CI runs 3.12; this machine's default is 3.11), `unittest`.

**Spec:** `docs/superpowers/specs/2026-10-13-podcast-clip-scout-design.md`

## Global Constraints

- Work on a new branch `podcast-clip-scout` cut from `main` (Task 1, Step 1). Do not push, merge, or change GitHub settings in this plan; the owner decides that after the final review.
- Standard library only. No new CI step; CI already runs `python -m unittest discover -s tests`.
- Module names carry a `pcs_` prefix (`pcs_transcript`, `pcs_picks`, `pcs_export`) so they cannot collide with other modules when the repo suite imports everything in one process. The CLI is `clips.py`.
- Exit codes: 0 clean; 1 picks invalid (`check` and `export`); 2 unreadable input, bad arguments or a file that cannot be written. Nothing is written when `export` exits 1 or 2.
- Rubric dimensions, in this order everywhere: `hook`, `standalone`, `emotion`, `payoff`, `quotable`. Each is a whole number 0 to 3; `total` is their sum (0 to 15). Ranking is by total descending, ties by `hook` then `standalone` descending.
- Length range default 20 to 60 seconds, overridden by `--min` and `--max`. Caption cap default 150 characters (`--max-caption`), described as this tool's own default and never as a platform rule. Gap warning threshold 5 seconds.
- Times are printed as `HH:MM:SS.mmm`. Durations are rounded to 3 decimals.
- Never print or write text outside the transcript's own cue text and the picks the user's Claude wrote. The skill makes no claim about what performs on any platform and never says the scores are validated.
- Write every file containing backslashes or many quotes with the Write or Edit tool, never a shell heredoc. Files the helper writes use LF line endings, except the CSV, which uses the csv module's default CRLF.
- Commit trailer on every commit: `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
- Repo rules: the README catalog and `llms.txt` are generated by `python scripts/build_catalog.py` (check with `--check`); existing files under `docs/superpowers/` other than this feature's are untouched; the old marketplace name appears nowhere.

## Review Focus

1. **Real transcript variety.** Whisper-style JSON (`{"segments": [...]}`), VTT with cue settings, `<v Name>` tags, NOTE blocks and `mm:ss.mmm` times, SRT with a BOM and CRLF, and cues that overlap or have empty text must parse or fail with a one-line message, never a traceback (Task 2).
2. **Wrong JSON types in picks.** A `picks.json` whose values have the wrong type (a string where a number belongs, `clips` not a list, `scores` not an object) must produce error lines and exit 1, never a traceback (Task 3; the same class of bug is open for pdf-table-fixer as issue #86).
3. **Cue numbers that do not exist.** Picks citing cues outside the transcript, swapped start and end, or a mid-sentence boundary must be reported as errors or warnings with the clip number (Task 3).
4. **Export is all or nothing.** `export` on invalid picks writes nothing and does not create the output folder; a caption starting with `=`, `+`, `-` or `@` must not become a spreadsheet formula in the CSV (Tasks 4, 5).
5. **Windows console and file encodings.** Non-ASCII transcript text must print without a UnicodeEncodeError, and a non-UTF-8 transcript must exit 2 with a message (Tasks 2, 5).

```python
def sample_cues():
    """24 cues of 5 seconds each, as (start, end, text)."""
    return [(i * 5.0, (i + 1) * 5.0, text) for i, text in enumerate(TEXTS)]


def cue_dicts():
    return [
        {"n": i, "start": s, "end": e, "text": t, "speaker": None}
        for i, (s, e, t) in enumerate(sample_cues(), 1)
    ]


def _stamp(seconds, sep):
    ms = round(seconds * 1000)
    h, rem = divmod(ms, 3600000)
    m, rem = divmod(rem, 60000)
    s, ms = divmod(rem, 1000)
    return f"{h:02d}:{m:02d}:{s:02d}{sep}{ms:03d}"


def srt(cues, crlf=False, bom=False):
    blocks = [
        f"{i}\n{_stamp(s, ',')} --> {_stamp(e, ',')}\n{t}"
        for i, (s, e, t) in enumerate(cues, 1)
    ]
    text = "\n\n".join(blocks) + "\n"
    if crlf:
        text = text.replace("\n", "\r\n")
    return ("﻿" if bom else "") + text


def vtt(cues):
    blocks = [f"{_stamp(s, '.')} --> {_stamp(e, '.')}\n{t}" for s, e, t in cues]
    return "WEBVTT\n\n" + "\n\n".join(blocks) + "\n"


def json_segments(cues):
    return json.dumps([{"start": s, "end": e, "text": t} for s, e, t in cues])


def ideal_picks():
    """Two clips that pass `check` with no errors and no warnings on sample_cues()."""
    def reasons(tag):
        return {d: f"{tag}: {d}" for d in ("hook", "standalone", "emotion", "payoff", "quotable")}

    return {
```

```python
"""Parse SRT, VTT and JSON transcripts into numbered cues. Standard library only."""
import html
import json
import math
import re
from pathlib import Path


class TranscriptError(Exception):
    """A transcript that cannot be read; the message is one line for the user."""


_TIME = r"(?:(\d+):)?(\d{1,2}):(\d{2})[.,](\d{1,3})"
_TIMING = re.compile(rf"^\s*{_TIME}\s*-->\s*{_TIME}(?:\s.*)?$")
_TAG = re.compile(r"<[^>]*>")
_VOICE = re.compile(r"<v(?:\.[^\s>]*)?\s+([^>]+)>")
_SKIP_BLOCK = re.compile(r"^(WEBVTT|NOTE|STYLE|REGION)(\s|$)")


def _ms(hours, minutes, seconds, fraction):
    whole = (int(hours or 0) * 60 + int(minutes)) * 60 + int(seconds)
    return whole * 1000 + int(fraction.ljust(3, "0"))


def _cue(n, start_ms, end_ms, text, speaker):
    return {"n": n, "start": start_ms / 1000, "end": end_ms / 1000, "text": text, "speaker": speaker}


def _parse_blocks(text):
    """SRT and VTT share one shape: blocks separated by blank lines, a timing line, then text."""
    text = text.replace("\r\n", "\n").replace("\r", "\n")
    found = []
    for block in re.split(r"\n\s*\n", text):
        lines = block.strip("\n").split("\n")
        if not lines or _SKIP_BLOCK.match(lines[0].strip()):
            continue
        timing_at = next((i for i, line in enumerate(lines) if _TIMING.match(line)), None)
        if timing_at is None:
            continue
        g = _TIMING.match(lines[timing_at]).groups()
        start_ms, end_ms = _ms(*g[:4]), _ms(*g[4:])
        if end_ms < start_ms:
            raise TranscriptError(f"a cue ends before it starts: {lines[timing_at].strip()}")
        raw = " ".join(lines[timing_at + 1:])
        voice = _VOICE.search(raw)
        speaker = voice.group(1).strip() if voice else None
        clean = " ".join(html.unescape(_TAG.sub("", raw)).split())
        if clean:
            found.append((start_ms, end_ms, clean, speaker))
    return found


def _number(value):
    return (
        isinstance(value, (int, float))
        and not isinstance(value, bool)
        and math.isfinite(value)
        and value >= 0
    )


def _parse_json(text):
    try:
        data = json.loads(text)
    except ValueError as exc:
        raise TranscriptError(f"invalid JSON: {exc}")
    if isinstance(data, dict) and isinstance(data.get("segments"), list):
        data = data["segments"]
    if not isinstance(data, list):
        raise TranscriptError("JSON must be a list of {start, end, text} segments")
    found = []
    for i, seg in enumerate(data, 1):
        if not isinstance(seg, dict):
            raise TranscriptError(f"segment {i} is not an object")
        start, end, words = seg.get("start"), seg.get("end"), seg.get("text")
        if not _number(start) or not _number(end):
            raise TranscriptError(f"segment {i} needs numeric start and end seconds")
        if not isinstance(words, str):
            raise TranscriptError(f"segment {i} needs a text string")
        if end < start:
            raise TranscriptError(f"segment {i} ends before it starts")
        speaker = seg.get("speaker")
        speaker = speaker.strip() if isinstance(speaker, str) and speaker.strip() else None
        clean = " ".join(words.split())
        if clean:
            found.append((round(start * 1000), round(end * 1000), clean, speaker))
    return found


def _is_json(path, text):
    if path.suffix.lower() == ".json":
        return True
    if path.suffix.lower() in (".srt", ".vtt"):
        return False
    return text.lstrip()[:1] in ("[", "{")


def parse_file(path):
    path = Path(path)
    try:
        raw = path.read_bytes()
    except OSError as exc:
        raise TranscriptError(f"cannot read {path}: {exc.strerror or exc}")
    try:
        text = raw.decode("utf-8-sig")
    except UnicodeDecodeError:
        raise TranscriptError(f"{path} is not valid UTF-8 text")
    if not text.strip():
        raise TranscriptError(f"{path} is empty")
    found = _parse_json(text) if _is_json(path, text) else _parse_blocks(text)
    if not found:
        raise TranscriptError(f"no cues found in {path}")
    return [_cue(n, *item[:3], item[3]) for n, item in enumerate(found, 1)]


def fmt_time(seconds):
    ms = round(seconds * 1000)
    hours, rem = divmod(ms, 3600000)
    minutes, rem = divmod(rem, 60000)
    secs, ms = divmod(rem, 1000)
    return f"{hours:02d}:{minutes:02d}:{secs:02d}.{ms:03d}"
```

```python
"""Validate the clips Claude picked. Standard library only.

The checks prove the list is consistent (real cues, lengths in range, no overlaps,
arithmetic and ordering right). They do not judge whether a hook is a good hook.
"""
import json
from pathlib import Path

DIMENSIONS = ("hook", "standalone", "emotion", "payoff", "quotable")
MAX_SCORE = 3
GAP_WARN_SECONDS = 5.0
_CLOSERS = "\"')]”’»"


class PicksError(Exception):
    """A picks file that cannot be read; the message is one line for the user."""


def load_picks(path):
    path = Path(path)
    try:
        raw = path.read_bytes()
    except OSError as exc:
        raise PicksError(f"cannot read {path}: {exc.strerror or exc}")
    try:
        data = json.loads(raw.decode("utf-8-sig"))
    except UnicodeDecodeError:
        raise PicksError(f"{path} is not valid UTF-8 text")
    except ValueError as exc:
        raise PicksError(f"{path} is not valid JSON: {exc}")
    if not isinstance(data, dict):
        raise PicksError(f'{path} must hold a JSON object with a "clips" list')
    return data


def _is_int(value):
    return isinstance(value, int) and not isinstance(value, bool)


def _ends_sentence(text):
    return text.rstrip().rstrip(_CLOSERS).endswith((".", "?", "!"))


def _check_range(tag, clip, cues, min_s, max_s, errors, warnings):
    """Returns (first_cue, last_cue, start, end) when the cue numbers are usable, else None."""
    first, last = clip.get("start_cue"), clip.get("end_cue")
    if not _is_int(first) or not _is_int(last):
        errors.append(f"{tag}: start_cue and end_cue must be whole cue numbers")
        return None
    missing = [n for n in (first, last) if not 1 <= n <= len(cues)]
    if missing:
        errors.append(f"{tag}: cue {missing[0]} does not exist (the transcript has cues 1-{len(cues)})")
        return None
    if first > last:
        errors.append(f"{tag}: start_cue {first} is after end_cue {last}")
        return None
    start, end = cues[first - 1]["start"], cues[last - 1]["end"]
    length = round(end - start, 3)
    if length < min_s or length > max_s:
        errors.append(f"{tag}: lasts {length:g}s, outside {min_s:g}-{max_s:g}s")
    if first > 1 and not _ends_sentence(cues[first - 2]["text"]):
        warnings.append(f"{tag}: starts mid-sentence (cue {first - 1} does not end a sentence)")
    if not _ends_sentence(cues[last - 1]["text"]):
        warnings.append(f"{tag}: ends mid-sentence (cue {last} does not end a sentence)")
    for k in range(first, last):
        gap = round(cues[k]["start"] - cues[k - 1]["end"], 3)
        if gap > GAP_WARN_SECONDS:
            warnings.append(f"{tag}: {gap:g}s gap between cues {k} and {k + 1}")
    return first, last, start, end


def _check_scores(tag, clip, errors):
    scores = clip.get("scores")
    if not isinstance(scores, dict):
        errors.append(f"{tag}: scores must be an object with {', '.join(DIMENSIONS)}")
        return None
    ok = True
    for dim in DIMENSIONS:
        if dim not in scores:
            errors.append(f"{tag}: scores is missing '{dim}'")
            ok = False
        elif not _is_int(scores[dim]) or not 0 <= scores[dim] <= MAX_SCORE:
            errors.append(f"{tag}: score '{dim}' must be a whole number from 0 to {MAX_SCORE}")
            ok = False
    for dim in scores:
        if dim not in DIMENSIONS:
            errors.append(f"{tag}: unknown score dimension {dim!r}")
            ok = False
    return scores if ok else None


def check(cues, picks, min_seconds=20.0, max_seconds=60.0, max_caption=150):
    """Returns (errors, warnings), two lists of one-line strings."""
    clips = picks.get("clips") if isinstance(picks, dict) else None
    if not isinstance(clips, list):
        return ['picks must be an object with a "clips" list'], []
    if not clips:
        return ["no clips: the list is empty"], []
    errors, warnings = [], []
    spans, keys = {}, {}
    for i, clip in enumerate(clips, 1):
        tag = f"clip {i}"
        if not isinstance(clip, dict):
            errors.append(f"{tag}: must be an object")
            continue
        span = _check_range(tag, clip, cues, min_seconds, max_seconds, errors, warnings)
        if span:
            spans[i] = span
        scores = _check_scores(tag, clip, errors)
        if scores is not None:
            expected = sum(scores[d] for d in DIMENSIONS)
            total = clip.get("total")
            if not _is_int(total) or total != expected:
                errors.append(f"{tag}: total is {total!r} but the scores add up to {expected}")
            keys[i] = (-expected, -scores["hook"], -scores["standalone"])
        reasons = clip.get("reasons")
        if not isinstance(reasons, dict):
            errors.append(f"{tag}: reasons must be an object with a line for each dimension")
        else:
            for dim in DIMENSIONS:
                line = reasons.get(dim)
                if not isinstance(line, str) or not line.strip():
                    errors.append(f"{tag}: reasons is missing a line for '{dim}'")
        caption = clip.get("caption")
        if not isinstance(caption, str) or not caption.strip():
            errors.append(f"{tag}: caption is missing")
        elif len(caption) > max_caption:
            errors.append(f"{tag}: caption is {len(caption)} characters, over {max_caption}")
    ids = sorted(spans)
    for pos, a in enumerate(ids):
        for b in ids[pos + 1:]:
            a_first, a_last, a_start, a_end = spans[a]
            b_first, b_last, b_start, b_end = spans[b]
            if (a_first <= b_last and b_first <= a_last) or (a_start < b_end and b_start < a_end):
                errors.append(f"clip {a} and clip {b} overlap")
    scored = sorted(keys)
    for before, after in zip(scored, scored[1:]):
        if keys[before] > keys[after]:
            errors.append(f"clips are not in ranked order: clip {after} should come before clip {before}")
    return errors, warnings
```

```python
"""Write the ranked clip list as CSV and JSON. Standard library only."""
import csv
import json
from pathlib import Path

from pcs_picks import DIMENSIONS
from pcs_transcript import fmt_time

CSV_COLUMNS = [
    "rank", "start", "end", "duration_seconds", "start_cue", "end_cue", "total",
    *DIMENSIONS, "caption",
]


def build_rows(cues, picks):
    """picks must already have passed pcs_picks.check; times come from the cues."""
    rows = []
    for rank, clip in enumerate(picks["clips"], 1):
        first, last = clip["start_cue"], clip["end_cue"]
        start, end = cues[first - 1]["start"], cues[last - 1]["end"]
        rows.append({
            "rank": rank,
            "start": fmt_time(start),
            "end": fmt_time(end),
            "duration_seconds": round(end - start, 3),
            "start_cue": first,
            "end_cue": last,
            "total": clip["total"],
            "scores": dict(clip["scores"]),
            "reasons": dict(clip["reasons"]),
            "caption": clip["caption"].strip(),
        })
    return rows


def _csv_safe(text):
    """A spreadsheet reads a leading = + - @ as a formula; a leading apostrophe stops that."""
    return "'" + text if text[:1] in ("=", "+", "-", "@", "\t", "\r") else text


def write_export(cues, picks, out_dir):
    out_dir = Path(out_dir)
    out_dir.mkdir(parents=True, exist_ok=True)
    rows = build_rows(cues, picks)
    json_path = out_dir / "clips.json"
    with open(json_path, "w", encoding="utf-8", newline="\n") as fh:
        fh.write(json.dumps({"clips": rows}, indent=2, ensure_ascii=False) + "\n")
    csv_path = out_dir / "clips.csv"
    with open(csv_path, "w", encoding="utf-8", newline="") as fh:
        writer = csv.writer(fh)
        writer.writerow(CSV_COLUMNS)
        for r in rows:
            writer.writerow([
                r["rank"], r["start"], r["end"], r["duration_seconds"], r["start_cue"],
                r["end_cue"], r["total"], *[r["scores"][d] for d in DIMENSIONS],
                _csv_safe(r["caption"]),
            ])
```

```python
#!/usr/bin/env python3
"""Podcast Clip Scout helper: cues | check | export. Standard library only.

Exit codes: 0 ok; 1 the picks are invalid; 2 unreadable input, bad arguments or an
output that cannot be written. Nothing is written unless the picks pass the check.
"""
import argparse
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent))
import pcs_export  # noqa: E402
import pcs_picks  # noqa: E402
import pcs_transcript  # noqa: E402


def build_parser():
    parser = argparse.ArgumentParser(
        prog="clips.py", description="Check and export podcast clip picks against a transcript."
    )
    sub = parser.add_subparsers(dest="command", required=True)

    cues = sub.add_parser("cues", help="print numbered, timestamped cues")
    cues.add_argument("transcript")
    cues.add_argument("--from", dest="first", type=int, default=1, help="first cue to print")
    cues.add_argument("--to", dest="last", type=int, default=None, help="last cue to print")

    for name, helptext in (("check", "validate picks.json"), ("export", "write ranked CSV and JSON")):
        sp = sub.add_parser(name, help=helptext)
        sp.add_argument("transcript")
        sp.add_argument("--picks", required=True)
        sp.add_argument("--min", dest="min_seconds", type=float, default=20.0)
        sp.add_argument("--max", dest="max_seconds", type=float, default=60.0)
        sp.add_argument("--max-caption", dest="max_caption", type=int, default=150)
        if name == "export":
            sp.add_argument("--out", required=True)
    return parser


def cmd_cues(args):
    cues = pcs_transcript.parse_file(args.transcript)
    first = args.first
    last = len(cues) if args.last is None else min(args.last, len(cues))
    if first < 1 or first > len(cues) or last < first:
        print(f"error: cue range {first}-{args.last} is not inside 1-{len(cues)}", file=sys.stderr)
        return 2
    for cue in cues[first - 1:last]:
        who = f"[{cue['speaker']}] " if cue["speaker"] else ""
        print(f"{cue['n']:>5}  {pcs_transcript.fmt_time(cue['start'])}  {who}{cue['text']}")
    return 0


def _checked(args):
    """Returns (cues, picks, errors, warnings) after printing the report, or None for exit 2."""
    if args.min_seconds < 0 or args.max_seconds < args.min_seconds or args.max_caption < 1:
        print("error: --min must be 0 or more, --max at least --min, --max-caption at least 1", file=sys.stderr)
        return None
    cues = pcs_transcript.parse_file(args.transcript)
    picks = pcs_picks.load_picks(args.picks)
    errors, warnings = pcs_picks.check(
        cues, picks, args.min_seconds, args.max_seconds, args.max_caption
    )
    for line in errors:
        print(f"ERROR {line}")
    for line in warnings:
        print(f"WARN {line}")
    return cues, picks, errors, warnings


def cmd_check(args):
    result = _checked(args)
    if result is None:
        return 2
    _, picks, errors, warnings = result
    if errors:
        print(f"{len(errors)} error(s), {len(warnings)} warning(s)")
        return 1
    print(f"ok: {len(picks['clips'])} clips ({len(warnings)} warning(s))")
    return 0


def cmd_export(args):
    result = _checked(args)
    if result is None:
        return 2
    cues, picks, errors, warnings = result
    if errors:
        print(f"{len(errors)} error(s), {len(warnings)} warning(s); nothing written")
        return 1
    try:
        csv_path, json_path = pcs_export.write_export(cues, picks, args.out)
    except OSError as exc:
        print(f"error: cannot write to {args.out}: {exc.strerror or exc}", file=sys.stderr)
        return 2
    print(f"wrote {csv_path}")
    print(f"wrote {json_path}")
    return 0


COMMANDS = {"cues": cmd_cues, "check": cmd_check, "export": cmd_export}


def main(argv=None):
    try:
        args = build_parser().parse_args(argv)
    except SystemExit as exc:
        return exc.code if isinstance(exc.code, int) else 2
    try:
        return COMMANDS[args.command](args)
    except (pcs_transcript.TranscriptError, pcs_picks.PicksError) as exc:
        print(f"error: {exc}", file=sys.stderr)
        return 2


def _utf8_streams():
    for stream in (sys.stdout, sys.stderr):
        try:
            stream.reconfigure(encoding="utf-8", errors="replace")
        except (AttributeError, ValueError):
            pass


if __name__ == "__main__":
    _utf8_streams()
    sys.exit(main())
```

````markdown
# Podcast Clip Scout

## Overview

Picks ranked short-form clip candidates from a timestamped transcript and writes a cut list. It chooses and describes moments; it does not cut audio or video, burn in captions or write show notes. You score each moment with a five-part rubric; a helper script reads the transcript, checks your picks and exports the list. The scores are your judgment and nothing here has validated them against human picks, so say that in your final message.

## The helper

`scripts/clips.py` in this skill's folder, Python 3 standard library only (use `python3`, or `python` / `py -3`, whichever works). Transcripts can be SRT, VTT or JSON (a list of `{start, end, text}` segments, or Whisper's `{"segments": [...]}`).

- `clips.py cues TRANSCRIPT [--from N] [--to M]`: prints every cue as a number, a timestamp and its text.
- `clips.py check TRANSCRIPT --picks picks.json [--min 20] [--max 60] [--max-caption 150]`: validates your picks. Exit 0 clean, 1 problems (read every `ERROR` line), 2 unreadable input.
- `clips.py export TRANSCRIPT --picks picks.json --out DIR`: runs the same check and, only if it is clean, writes `clips.csv` and `clips.json`.

## The rubric

Score each candidate on five dimensions, each a whole number from 0 to 3. `total` is their sum. Rank by total, highest first; break ties by `hook`, then `standalone`.

| Dimension | 0 | 1 | 2 | 3 |
| --- | --- | --- | --- | --- |
| `hook` | Opens on filler or a greeting | Weak opening, but a real point arrives within about 10 seconds | Opens on the topic with some pull | The first sentence grabs: a claim, question, surprise or conflict |
| `standalone` | Needs earlier context to follow | Needs one fact a caption could supply | Clear except one minor reference | A stranger understands it cold |
| `emotion` | Flat | Mild interest or amusement | Clear emotion or a real surprise | Laughter, anger, vulnerability or strong surprise |
| `payoff` | Trails off or cuts mid-thought | Ends on a point, not a conclusion | Ends on a clear conclusion without a final punch | A punchline, conclusion or takeaway lands at the end |
| `quotable` | Nothing worth repeating | A decent sentence | A strong line, but wordy | A line someone would screenshot or caption |

## Process

1. **Read.** Run `clips.py cues` on the transcript and read all of it. If it is too long to read at once, read it in ranges with `--from` and `--to`, overlapping each range by enough cues to hold a whole clip, collect candidates from each range, and rank across all of them.
2. **Pick.** Choose the requested number of clips (default 5). If the episode does not hold that many good moments, return fewer and say so; never pad. A clip is a run of whole cues. Start on a cue that begins a sentence and end on one that finishes a thought. Keep it inside the length range (default 20 to 60 seconds; the user may give another).
3. **Write `picks.json`** next to the transcript, citing cue numbers only. Never type a timestamp; the helper derives times from the cues.
4. **Check.** Run `clips.py check`. Fix every `ERROR` and re-run until it is clean. A `WARN` (a clip that starts or ends mid-sentence, or has a gap inside it) is yours to judge: fix it or keep it, and mention a kept one.
5. **Export.** Run `clips.py export` with `--out` set to a folder the user names (or a new one beside the transcript).
6. **Report.** Show the ranked table (rank, start, end, total, caption) and the output folder. State plainly that the scores are your judgment and have not been validated against human picks.

## picks.json

```json
{"clips": [{
  "start_cue": 41, "end_cue": 58,
  "scores": {"hook": 3, "standalone": 2, "emotion": 2, "payoff": 3, "quotable": 1},
  "total": 11,
  "reasons": {"hook": "one line each", "standalone": "...", "emotion": "...", "payoff": "...", "quotable": "..."},
  "caption": "The line to post with the clip"
}]}
```

## What to tell the user

- This reads text only. Tone of voice, laughter that is not in the transcript, and anything visual are invisible to it.
- The check proves the list is consistent (real cues, lengths in range, no overlaps, arithmetic and order right). It does not prove a hook is a good hook.
- The skill makes no claim about what performs well on any platform. The 150-character caption cap is this tool's own default, not a platform rule.
- Transcript quality caps the result: wrong timestamps or missing speaker labels give wrong clips. If speakers matter and the transcript has none, ask instead of guessing.
- Cutting the clips is a separate step (for example `podcast-use` or `ffmpeg`), using the start and end times in `clips.csv`.

## Common mistakes

| Mistake | Fix |
| --- | --- |
| Typing timestamps into picks.json | Cite cue numbers only; times come from the cues |
| Scoring every clip 2s and 3s | Use the full 0 to 3 range; a clip that needs context scores `standalone` 0 or 1 |
| Padding to hit the count | Return fewer clips and say why |
| Skipping `check` before `export` | `export` re-checks and writes nothing on errors; run `check` first so you can fix them |
| Ranking by gut after scoring | The list must be in rank order: total, then `hook`, then `standalone` |
````
